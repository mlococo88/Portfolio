Alerts

Checked on every price refresh while this page is open, and every 5 minutes by the GitHub checker when it isn't. Price and account-total alerts fire once and wait to be re-armed; day-change alerts re-arm automatically each trading day; "repeating" alerts fire each time the price moves the given amount from where it last notified you. Add your ntfy topic in Settings to get phone notifications from either path.

    Prices

    Sign up at alpaca.markets (a free paper-trading account is enough), then in the dashboard generate an API key. You get a Key ID and a Secret — paste both. Regular-session quotes are real-time from IEX; outside the session the app also pulls Alpaca's free 15-minute-delayed consolidated feed for better pre-market and after-hours coverage.

    Get a free key at finnhub.io. Note: the free tier's quote may lag or omit extended-hours trades.

    Sync across devices

    Your data is saved in this browser. To share it between your computer and phone, it's stored in a private GitHub Gist. Create a token at github.com/settings/tokens with the Gists permission (read and write). Paste the same token and Gist ID on each device; leave Gist ID blank the first time and one is created for you.

    Phone notifications

    Install the ntfy app and subscribe to a private topic; enter the same topic here (and as the NTFY_TOPIC secret for the GitHub checker). Alerts that fire while the app is open are then pushed to your phone too.

    Backup

    The download holds holdings, cash, history, alerts and the projection plan — not your API keys or tokens.

    Open this page in Safari (iPhone) or Chrome (Android), then use Share → Add to Home Screen. It opens full-screen like an app.
