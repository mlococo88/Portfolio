Where this is headed

Starts from today's account total. The dashed line is a steady return; the shaded band is the 10th–90th percentile of 600 simulated paths using the volatility you set. Contributions are added monthly.

Alerts

Checked on every price refresh while this page is open. If you allow notifications, the app will also post a system notification. Alerts don't run while the page is closed.

    Prices

    Quotes come from Finnhub. A free key gives real-time US prices, including pre- and post-market trades. Get one at finnhub.io.

    Sync across devices

    Your data is saved in this browser. To share it between your computer and phone, it's stored in a private GitHub Gist. Create a token at github.com/settings/tokens with the Gists permission (read and write). Paste the same token and Gist ID on each device; leave Gist ID blank the first time and one is created for you.
